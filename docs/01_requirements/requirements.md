# 要件定義書 — aituber MVP

## 1. 概要

録画済みゲーム動画（MP4）を入力として、AI が実況テキスト・音声・字幕を自動生成し、実況付き動画を出力するシステム。

---

## 2. MVP スコープ

### 対象とする機能

- 動画をセグメント単位に分割する
- 各セグメントからフレームを抽出する
- ゲームイベントを検出する（MVP ではダミー実装可）
- イベントから発話計画を生成する
- LLM で実況テキストを生成する
- Qwen TTS で音声を合成する
- SRT 字幕を生成する
- 音声・字幕を動画に合成して出力する

### 対象外（MVP スコープ外）

- Web UI / フロントエンド
- リアルタイム処理
- 複数ゲームタイトル対応
- ユーザー認証・マルチテナント

---

## 3. 機能要件

### F-01: 動画インジェスト
- MP4 形式の動画ファイルを受け付ける
- `videos` テーブルにメタデータを登録する
- ローカルストレージ（`MEDIA_ROOT`）にファイルを保存する

### F-02: 動画分割
- `SEGMENT_DURATION`（デフォルト 5 秒）単位で動画を分割する
- `segments` テーブルに分割情報を保存する

### F-03: フレーム抽出
- 各セグメントから代表フレームを抽出する
- `frames` テーブルに保存する

### F-04: イベント生成
- フレームを解析してゲームイベントを検出する
- `events` テーブルに保存する
- MVP ではダミー実装（固定 JSON を返却）でよい

### F-05: 発話計画
- イベントリストから発話単位を決定する
- 連続発話を抑制する（`EVENT_GROUPING_WINDOW` 秒以内の重複をまとめる）
- `utterance_plans` テーブルに保存する

### F-06: 実況生成
- 発話計画を LLM に渡して実況テキストを生成する
- 1〜2 文・口語・日本語で生成する
- `commentaries` テーブルに保存する

### F-07: 音声合成
- Qwen TTS API（`/tts/custom-voice`）を呼び出して WAV を生成する
- 音声長を取得する
- `audios` テーブルに保存する

### F-08: 字幕生成
- 音声長ベースで SRT ファイルを生成する
- `subtitles` テーブルに保存する

### F-09: 動画合成
- FFmpeg で音声・字幕・元動画を合成して MP4 を出力する

---

## 4. 非機能要件

| 項目 | 目標値 |
|---|---|
| 処理時間（1 分動画） | 5 分以内（MVP 基準） |
| 字幕同期精度 | 音声とのズレ 0.5 秒以内 |
| 実況文の自然さ | 5 段階評価平均 4.0 以上（人間評価） |

---

## 5. 制約事項

- 初期実装はオフライン処理（リアルタイムなし）
- TTS は自前 Qwen TTS サーバー（`TTS_BASE_URL`）を使用
- LLM は OpenAI 互換 API（`LLM_API_BASE`）を使用
- ストレージはローカルファイルシステム（S3 等は Phase 3 以降）
